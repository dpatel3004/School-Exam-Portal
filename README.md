# 📋 School Exam Paper Registration Portal

A full-stack web portal developed for **Sardar Patel Pariksha Sankul, Anand** — digitising the exam paper requirement submission process for schools across Anand district, replacing a manual paper-based workflow entirely.

---

## 🌟 Overview

School principals log in and digitally submit their exam paper requirements (subject-wise, standard-wise paper quantities). The admin then manages all submissions through a powerful dashboard — viewing, printing, generating bills, and exporting data — all from one place.

---

## 👥 User Roles

### 🏫 Principal
- Secure login to the portal
- Fill and submit exam paper requirements (standard-wise, subject-wise quantities)
- View submission status

### 🛠️ Admin
- View a list of all registered schools
- Click on any school to see:
  - School name & principal name
  - Standard-wise subject paper quantities
  - Total papers required per standard
- Print individual school paper requirements
- Generate exam bills for each school separately for:
  - **First Exam**
  - **Second Exam**
- Print generated bills directly from the portal
- Access a **Summary Dashboard** showing:
  - Which school needs papers for which subjects
  - Paper quantities per subject per school
  - **Download full summary as an Excel file** (`.xlsx`)

---

## ✨ Key Features

- 🔐 Firebase Authentication — secure role-based login for principals and admin
- 📋 Multi-step form flow for paper requirement submission
- 📊 Admin dashboard with school-wise analytics
- 🧾 Gujarati exam bill generation (First & Second exam separately)
- 🖨️ Print support for bills and paper requirement sheets
- 📥 Excel export of summary data using ExcelJS
- 📄 PDF download support using jsPDF
- 📱 Fully mobile-responsive UI
